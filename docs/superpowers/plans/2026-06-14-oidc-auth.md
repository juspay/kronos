# OIDC Authentication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Kronos's single shared `TE_API_KEY` bearer token with a real OIDC-based auth model that accepts `Authorization: Bearer <jwt>` (validated against the configured issuer's JWKS) and `Authorization: Basic <id:secret>` (exchanged against the IdP's `client_credentials` grant and cached), with a `TE_AUTH_MODE=disabled` bypass for local dev. The dashboard becomes a public OIDC client doing PKCE in WASM. No new database tables, no Kronos-managed credentials — all secret material lives in the IdP.

**Architecture:** A small `auth` module in `crates/common` defines `Identity` (variants by credential format: `Bearer(Claims)` / `Basic(Claims)` / `Disabled`), a JWT `Validator` (JWKS-backed), and a `BasicExchanger` (in-process cache + per-`client_id` single-flight + 30 s negative cache, capped by `TE_OIDC_BASIC_CACHE_TTL_SEC`). An Actix `AuthMiddleware` in `crates/api` runs before `/v1/*` and injects `Identity` into request extensions. The Leptos/WASM dashboard runs authorization-code + PKCE itself, holds tokens in memory only (no refresh tokens, no web-storage persistence), and re-authenticates by bouncing through `/authorize` on expiry. The full design lives in `docs/superpowers/specs/2026-06-14-oidc-auth-design.md`.

**Tech Stack:** Rust 1.75+ (workspace), Actix-Web 4, sqlx (existing — unchanged for this work), the `openidconnect = "3"` crate for OIDC discovery/JWKS/JWT verification on the server side, `jsonwebtoken = "9"` for browser-side JWT verification (WASM-friendly), `getrandom` for PKCE secret material, `wiremock` for mock-IdP integration tests, Leptos 0.7 (existing) for the dashboard.

```rust
/// Auth configuration parsed from `TE_*` environment variables.
#[derive(Debug, Clone)]
pub enum AuthConfig {
    Disabled,
    Enabled {
        issuer: String,
        audiences: Vec<String>,
        basic_audience: Option<String>,
        basic_scope: Option<String>,
        basic_cache_ttl: Duration,
        jwks_refresh: Duration,
    },
}

impl AuthConfig {
    /// Parse from the process environment. Returns a descriptive `Err` when
    /// `TE_AUTH_MODE=enabled` and any required OIDC env is missing.
    pub fn from_env() -> Result<Self, String> {
        let mode = get_from_env_or_default("TE_AUTH_MODE", "enabled".to_string())
            .to_lowercase();
        match mode.as_str() {
            "disabled" => Ok(AuthConfig::Disabled),
            "enabled" => Self::enabled_from_env(),
            other => Err(format!(
                "TE_AUTH_MODE must be 'enabled' or 'disabled', got '{other}'"
            )),
        }
    }

    fn enabled_from_env() -> Result<Self, String> {
        let issuer = std::env::var("TE_OIDC_ISSUER").map_err(|_| {
            "TE_OIDC_ISSUER is required when TE_AUTH_MODE=enabled".to_string()
        })?;
        let audiences_raw = std::env::var("TE_OIDC_AUDIENCES").map_err(|_| {
            "TE_OIDC_AUDIENCES is required when TE_AUTH_MODE=enabled \
             (comma-separated list of accepted `aud` values)"
                .to_string()
        })?;
        let audiences: Vec<String> = audiences_raw
            .split(',')
            .map(|s| s.trim().to_string())
            .filter(|s| !s.is_empty())
            .collect();
        if audiences.is_empty() {
            return Err("TE_OIDC_AUDIENCES must contain at least one value".into());
        }
        let basic_audience = std::env::var("TE_OIDC_BASIC_AUDIENCE").ok().filter(|s| !s.is_empty());
        let basic_scope = std::env::var("TE_OIDC_BASIC_SCOPE").ok().filter(|s| !s.is_empty());
        let basic_cache_ttl =
            Duration::from_secs(get_from_env_or_default("TE_OIDC_BASIC_CACHE_TTL_SEC", 3600u64));
        let jwks_refresh =
            Duration::from_secs(get_from_env_or_default("TE_OIDC_JWKS_REFRESH_SEC", 300u64));

        Ok(AuthConfig::Enabled {
            issuer,
            audiences,
            basic_audience,
            basic_scope,
            basic_cache_ttl,
            jwks_refresh,
        })
    }
}
```

Create the file (this is a long-ish file; structure first, tests at the bottom):

```rust
use crate::auth::{AuthError, Claims};
use openidconnect::core::{CoreClient, CoreJsonWebKeySet, CoreProviderMetadata};
use openidconnect::reqwest::async_http_client;
use openidconnect::{
    AccessToken, Audience, ClientId, ClientSecret, IssuerUrl, JsonWebKeySetUrl, Nonce,
};
use serde::Deserialize;
use std::sync::Arc;
use std::time::Duration;
use tokio::sync::RwLock;

/// Validates JWTs against the configured OIDC issuer's JWKS.
///
/// JWKS is fetched at construction time (best-effort; failure leaves the cache
/// empty and is reported on validate()), and refreshed in the background at
/// `jwks_refresh` intervals.
#[derive(Clone)]
pub struct Validator {
    inner: Arc<ValidatorInner>,
}

struct ValidatorInner {
    issuer: String,
    audiences: Vec<String>,
    jwks: RwLock<Option<CoreJsonWebKeySet>>,
    jwks_url: JsonWebKeySetUrl,
    jwks_refresh: Duration,
}

impl Validator {
    /// Build by performing OIDC discovery against `issuer`. The JWKS is
    /// fetched once before this returns. A background task refreshes JWKS
    /// every `jwks_refresh`.
    pub async fn new(
        issuer: String,
        audiences: Vec<String>,
        jwks_refresh: Duration,
    ) -> Result<Self, AuthError> {
        let issuer_url = IssuerUrl::new(issuer.clone())
            .map_err(|e| AuthError::IdpMalformedResponse(format!("issuer url: {e}")))?;
        let metadata = CoreProviderMetadata::discover_async(issuer_url, async_http_client)
            .await
            .map_err(|e| AuthError::IdpUnreachable(format!("discovery: {e}")))?;
        let jwks_url = metadata.jwks_uri().clone();
        let jwks = CoreJsonWebKeySet::fetch_async(&jwks_url, async_http_client)
            .await
            .ok();
        let inner = Arc::new(ValidatorInner {
            issuer,
            audiences,
            jwks: RwLock::new(jwks),
            jwks_url,
            jwks_refresh,
        });
        let bg = inner.clone();
        tokio::spawn(async move { bg.refresh_loop().await });
        Ok(Self { inner })
    }

    /// Validate a raw JWT string. Returns the extracted Claims on success.
    pub async fn validate(&self, raw_jwt: &str) -> Result<Claims, AuthError> {
        // The openidconnect crate ties JWT verification to its higher-level
        // flows; for raw access-token validation we use jsonwebtoken with the
        // JWKS we fetched from discovery.
        let jwks = self.inner.jwks.read().await.clone();
        let jwks = jwks.ok_or_else(|| AuthError::IdpUnreachable("jwks not loaded yet".into()))?;

        let header = jsonwebtoken::decode_header(raw_jwt).map_err(|_| AuthError::MalformedHeader)?;
        let kid = header.kid.ok_or(AuthError::MalformedHeader)?;

        let jwk = jwks
            .keys()
            .iter()
            .find(|k| k.key_id().map(|kid_val| kid_val.as_str() == kid).unwrap_or(false))
            .ok_or(AuthError::BadSignature)?;

        // Convert the openidconnect JWK into a jsonwebtoken DecodingKey.
        // We support RS256 / ES256 (the common cases for OIDC); anything
        // else is rejected as a bad signature.
        let decoding_key = jwk_to_decoding_key(jwk)?;
        let mut validation = jsonwebtoken::Validation::new(jwk_to_algorithm(jwk)?);
        validation.set_issuer(&[self.inner.issuer.as_str()]);
        validation.set_audience(&self.inner.audiences);
        validation.leeway = 60;

        let token = jsonwebtoken::decode::<RawClaims>(raw_jwt, &decoding_key, &validation)
            .map_err(|e| match e.kind() {
                jsonwebtoken::errors::ErrorKind::ExpiredSignature => AuthError::Expired,
                jsonwebtoken::errors::ErrorKind::InvalidAudience => AuthError::BadAudience,
                jsonwebtoken::errors::ErrorKind::InvalidIssuer => {
                    AuthError::BadIssuer(self.inner.issuer.clone())
                }
                _ => AuthError::BadSignature,
            })?;

        Ok(Claims {
            iss: token.claims.iss,
            sub: token.claims.sub,
            email: token.claims.email,
            name: token.claims.name,
            scopes: parse_scopes(token.claims.scope.as_deref(), token.claims.scp.as_deref()),
        })
    }

    /// Force a JWKS refetch. Used by tests and on `kid` cache misses.
    pub async fn refresh_jwks(&self) -> Result<(), AuthError> {
        let fresh = CoreJsonWebKeySet::fetch_async(&self.inner.jwks_url, async_http_client)
            .await
            .map_err(|e| AuthError::IdpUnreachable(format!("jwks refresh: {e}")))?;
        *self.inner.jwks.write().await = Some(fresh);
        Ok(())
    }
}

impl ValidatorInner {
    async fn refresh_loop(self: Arc<Self>) {
        let mut ticker = tokio::time::interval(self.jwks_refresh);
        ticker.tick().await; // skip immediate tick
        loop {
            ticker.tick().await;
            if let Ok(fresh) =
                CoreJsonWebKeySet::fetch_async(&self.jwks_url, async_http_client).await
            {
                *self.jwks.write().await = Some(fresh);
            } else {
                tracing::warn!("JWKS refresh failed; will retry next interval");
            }
        }
    }
}

#[derive(Deserialize)]
struct RawClaims {
    iss: String,
    sub: String,
    #[serde(default)]
    email: Option<String>,
    #[serde(default)]
    name: Option<String>,
    #[serde(default)]
    scope: Option<String>, // RFC 6749 — space-separated string
    #[serde(default)]
    scp: Option<Vec<String>>, // Azure AD — array of strings
}

fn parse_scopes(scope: Option<&str>, scp: Option<&[String]>) -> Vec<String> {
    if let Some(s) = scope {
        return s.split_whitespace().map(String::from).collect();
    }
    if let Some(arr) = scp {
        return arr.to_vec();
    }
    Vec::new()
}

fn jwk_to_decoding_key(
    jwk: &openidconnect::core::CoreJsonWebKey,
) -> Result<jsonwebtoken::DecodingKey, AuthError> {
    use openidconnect::JsonWebKeyType;
    match jwk.key_type() {
        openidconnect::core::CoreJsonWebKeyType::RSA => {
            let n = jwk.n_b64().ok_or(AuthError::BadSignature)?;
            let e = jwk.e_b64().ok_or(AuthError::BadSignature)?;
            jsonwebtoken::DecodingKey::from_rsa_components(n, e)
                .map_err(|_| AuthError::BadSignature)
        }
        openidconnect::core::CoreJsonWebKeyType::EllipticCurve => {
            let x = jwk.x_b64().ok_or(AuthError::BadSignature)?;
            let y = jwk.y_b64().ok_or(AuthError::BadSignature)?;
            jsonwebtoken::DecodingKey::from_ec_components(x, y)
                .map_err(|_| AuthError::BadSignature)
        }
        _ => Err(AuthError::BadSignature),
    }
}

fn jwk_to_algorithm(
    jwk: &openidconnect::core::CoreJsonWebKey,
) -> Result<jsonwebtoken::Algorithm, AuthError> {
    // Most JWKs expose `alg`; fall back to a sensible default by key type.
    if let Some(alg) = jwk.signing_alg() {
        return match alg.as_str() {
            "RS256" => Ok(jsonwebtoken::Algorithm::RS256),
            "RS384" => Ok(jsonwebtoken::Algorithm::RS384),
            "RS512" => Ok(jsonwebtoken::Algorithm::RS512),
            "ES256" => Ok(jsonwebtoken::Algorithm::ES256),
            "ES384" => Ok(jsonwebtoken::Algorithm::ES384),
            _ => Err(AuthError::BadSignature),
        };
    }
    match jwk.key_type() {
        openidconnect::core::CoreJsonWebKeyType::RSA => Ok(jsonwebtoken::Algorithm::RS256),
        openidconnect::core::CoreJsonWebKeyType::EllipticCurve => Ok(jsonwebtoken::Algorithm::ES256),
        _ => Err(AuthError::BadSignature),
    }
}
```

```rust
use crate::auth::AuthError;
use dashmap::DashMap;
use sha2::{Digest, Sha256};
use std::sync::Arc;
use std::time::{Duration, Instant};
use tokio::sync::Mutex;

/// In-memory cache + IdP token-endpoint client for the Basic credential path.
///
/// Invariants:
/// - At most one outbound exchange in flight per `client_id` (single-flight).
/// - Successful exchanges are cached until `min(jwt.exp, hard_ttl) - 60s`.
/// - Failed exchanges (IdP 4xx) are negatively cached for 30s.
/// - Transient errors (IdP 5xx, network) are negatively cached for 5s.
#[derive(Clone)]
pub struct BasicExchanger {
    inner: Arc<ExchangerInner>,
}

struct ExchangerInner {
    token_endpoint: String,
    audience: Option<String>,
    scope: Option<String>,
    hard_ttl: Duration,
    positive: DashMap<CacheKey, CachedToken>,
    negative: DashMap<CacheKey, NegativeEntry>,
    inflight: DashMap<String, Arc<Mutex<()>>>,
    http: reqwest::Client,
}

#[derive(PartialEq, Eq, Hash, Clone)]
struct CacheKey {
    client_id: String,
    secret_hash: [u8; 32],
}

struct CachedToken {
    jwt: String,
    expires_at: Instant,
}

struct NegativeEntry {
    until: Instant,
    error: NegativeReason,
}

#[derive(Clone, Copy)]
enum NegativeReason {
    Rejected,
    Transient,
}

#[derive(serde::Deserialize)]
struct TokenResponse {
    access_token: String,
    #[serde(default)]
    expires_in: Option<u64>,
}

impl BasicExchanger {
    /// Build by performing OIDC discovery to locate the token endpoint.
    pub async fn new(
        issuer: String,
        audience: Option<String>,
        scope: Option<String>,
        hard_ttl: Duration,
    ) -> Result<Self, AuthError> {
        let discovery_url = format!("{}/.well-known/openid-configuration", issuer.trim_end_matches('/'));
        let resp: serde_json::Value = reqwest::Client::new()
            .get(&discovery_url)
            .send()
            .await
            .map_err(|e| AuthError::IdpUnreachable(format!("discovery: {e}")))?
            .json()
            .await
            .map_err(|e| AuthError::IdpMalformedResponse(format!("discovery: {e}")))?;
        let token_endpoint = resp
            .get("token_endpoint")
            .and_then(|v| v.as_str())
            .ok_or_else(|| {
                AuthError::IdpMalformedResponse("discovery missing token_endpoint".into())
            })?
            .to_string();
        Ok(Self {
            inner: Arc::new(ExchangerInner {
                token_endpoint,
                audience,
                scope,
                hard_ttl,
                positive: DashMap::new(),
                negative: DashMap::new(),
                inflight: DashMap::new(),
                http: reqwest::Client::new(),
            }),
        })
    }

    /// Exchange Basic credentials for an access-token JWT.
    pub async fn exchange(&self, client_id: &str, secret: &str) -> Result<String, AuthError> {
        let key = CacheKey {
            client_id: client_id.to_string(),
            secret_hash: hash_secret(secret),
        };

        if let Some(cached) = self.inner.positive.get(&key) {
            if cached.expires_at > Instant::now() {
                return Ok(cached.jwt.clone());
            }
        }
        if let Some(neg) = self.inner.negative.get(&key) {
            if neg.until > Instant::now() {
                return Err(match neg.error {
                    NegativeReason::Rejected => AuthError::IdpRejected,
                    NegativeReason::Transient => {
                        AuthError::IdpUnreachable("recent transient failure".into())
                    }
                });
            }
        }

        let lock = self
            .inner
            .inflight
            .entry(client_id.to_string())
            .or_insert_with(|| Arc::new(Mutex::new(())))
            .clone();
        let _guard = lock.lock().await;

        // Re-check cache after acquiring the lock (someone may have populated it).
        if let Some(cached) = self.inner.positive.get(&key) {
            if cached.expires_at > Instant::now() {
                return Ok(cached.jwt.clone());
            }
        }

        let result = self.exchange_inner(client_id, secret).await;
        match &result {
            Ok((jwt, expires_in)) => {
                let ttl = expires_in
                    .map(Duration::from_secs)
                    .unwrap_or(self.inner.hard_ttl)
                    .min(self.inner.hard_ttl)
                    .saturating_sub(Duration::from_secs(60));
                self.inner.positive.insert(
                    key.clone(),
                    CachedToken {
                        jwt: jwt.clone(),
                        expires_at: Instant::now() + ttl,
                    },
                );
                self.inner.negative.remove(&key);
            }
            Err(AuthError::IdpRejected) => {
                self.inner.negative.insert(
                    key,
                    NegativeEntry {
                        until: Instant::now() + Duration::from_secs(30),
                        error: NegativeReason::Rejected,
                    },
                );
            }
            Err(AuthError::IdpUnreachable(_)) => {
                self.inner.negative.insert(
                    key,
                    NegativeEntry {
                        until: Instant::now() + Duration::from_secs(5),
                        error: NegativeReason::Transient,
                    },
                );
            }
            _ => {}
        }
        result.map(|(jwt, _)| jwt)
    }

    /// Flush cache entries. `client_id = None` flushes all.
    /// Returns (positive_evicted, negative_evicted).
    pub fn flush(&self, client_id: Option<&str>) -> (usize, usize) {
        let pos_before = self.inner.positive.len();
        let neg_before = self.inner.negative.len();
        if let Some(cid) = client_id {
            self.inner.positive.retain(|k, _| k.client_id != cid);
            self.inner.negative.retain(|k, _| k.client_id != cid);
        } else {
            self.inner.positive.clear();
            self.inner.negative.clear();
        }
        (
            pos_before - self.inner.positive.len(),
            neg_before - self.inner.negative.len(),
        )
    }

    async fn exchange_inner(
        &self,
        client_id: &str,
        secret: &str,
    ) -> Result<(String, Option<u64>), AuthError> {
        let mut form: Vec<(&str, &str)> = vec![
            ("grant_type", "client_credentials"),
            ("client_id", client_id),
            ("client_secret", secret),
        ];
        if let Some(a) = &self.inner.audience {
            form.push(("audience", a));
        }
        if let Some(s) = &self.inner.scope {
            form.push(("scope", s));
        }

        let resp = self
            .inner
            .http
            .post(&self.inner.token_endpoint)
            .form(&form)
            .send()
            .await
            .map_err(|e| AuthError::IdpUnreachable(format!("token POST: {e}")))?;

        let status = resp.status();
        if status == reqwest::StatusCode::UNAUTHORIZED
            || status == reqwest::StatusCode::FORBIDDEN
            || status == reqwest::StatusCode::BAD_REQUEST
        {
            return Err(AuthError::IdpRejected);
        }
        if !status.is_success() {
            return Err(AuthError::IdpUnreachable(format!(
                "token endpoint status {status}"
            )));
        }
        let body: TokenResponse = resp
            .json()
            .await
            .map_err(|e| AuthError::IdpMalformedResponse(format!("token body: {e}")))?;
        Ok((body.access_token, body.expires_in))
    }
}

fn hash_secret(secret: &str) -> [u8; 32] {
    let mut hasher = Sha256::new();
    hasher.update(secret.as_bytes());
    hasher.finalize().into()
}
```

```rust
use actix_web::{HttpMessage, HttpResponse};
use base64::Engine;
use kronos_common::auth::{AuthConfig, AuthError, BasicExchanger, Identity, Validator};
use std::rc::Rc;

/// Actix middleware that authenticates inbound requests against the configured
/// auth model and injects an `Identity` into request extensions.
pub struct Auth {
    pub config: Rc<AuthState>,
}

/// Shared, runtime-built auth state: the validator and Basic exchanger plus
/// the parsed config. `None` for `validator`/`exchanger` means we're running
/// in disabled mode.
pub struct AuthState {
    pub mode: AuthMode,
}

pub enum AuthMode {
    Disabled,
    Enabled {
        validator: Validator,
        exchanger: BasicExchanger,
    },
}

impl<S, B> Transform<S, ServiceRequest> for Auth
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error> + 'static,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type InitError = ();
    type Transform = AuthMiddleware<S>;
    type Future = Ready<Result<Self::Transform, Self::InitError>>;

    fn new_transform(&self, service: S) -> Self::Future {
        future::ready(Ok(AuthMiddleware {
            service: Rc::new(service),
            state: self.config.clone(),
        }))
    }
}

pub struct AuthMiddleware<S> {
    service: Rc<S>,
    state: Rc<AuthState>,
}

impl<S, B> Service<ServiceRequest> for AuthMiddleware<S>
where
    S: Service<ServiceRequest, Response = ServiceResponse<B>, Error = Error> + 'static,
    S::Future: 'static,
    B: 'static,
{
    type Response = ServiceResponse<B>;
    type Error = Error;
    type Future = Pin<Box<dyn Future<Output = Result<Self::Response, Self::Error>>>>;

    forward_ready!(service);

    fn call(&self, req: ServiceRequest) -> Self::Future {
        let service = self.service.clone();
        let state = self.state.clone();
        Box::pin(async move {
            let identity = match resolve_identity(&state, &req).await {
                Ok(id) => id,
                Err(e) => return Ok(req.error_response(auth_error_response(e))),
            };
            req.extensions_mut().insert(identity);
            service.call(req).await
        })
    }
}

async fn resolve_identity(
    state: &AuthState,
    req: &ServiceRequest,
) -> Result<Identity, AuthError> {
    match &state.mode {
        AuthMode::Disabled => Ok(Identity::Disabled),
        AuthMode::Enabled { validator, exchanger } => {
            let header = req
                .headers()
                .get("authorization")
                .and_then(|v| v.to_str().ok())
                .ok_or(AuthError::MissingHeader)?;
            if let Some(token) = header.strip_prefix("Bearer ") {
                let claims = validator.validate(token).await?;
                Ok(Identity::Bearer(claims))
            } else if let Some(b64) = header.strip_prefix("Basic ") {
                let decoded = base64::engine::general_purpose::STANDARD
                    .decode(b64.trim())
                    .map_err(|_| AuthError::MalformedHeader)?;
                let s = std::str::from_utf8(&decoded).map_err(|_| AuthError::MalformedHeader)?;
                let (id, secret) = s.split_once(':').ok_or(AuthError::MalformedHeader)?;
                let jwt = exchanger.exchange(id, secret).await?;
                let claims = validator.validate(&jwt).await?;
                Ok(Identity::Basic(claims))
            } else {
                Err(AuthError::MalformedHeader)
            }
        }
    }
}

fn auth_error_response(err: AuthError) -> actix_web::Error {
    let body = serde_json::json!({
        "error": { "code": code_for(&err), "message": err.to_string() }
    });
    let response = match err {
        AuthError::IdpUnreachable(_) => HttpResponse::ServiceUnavailable()
            .insert_header(("Retry-After", "5"))
            .json(body),
        _ => HttpResponse::Unauthorized().json(body),
    };
    actix_web::error::InternalError::from_response("auth", response).into()
}

fn code_for(err: &AuthError) -> &'static str {
    match err {
        AuthError::MissingHeader => "MISSING_AUTHORIZATION",
        AuthError::MalformedHeader => "MALFORMED_AUTHORIZATION",
        AuthError::InvalidCredentials | AuthError::IdpRejected => "INVALID_CREDENTIALS",
        AuthError::Expired => "TOKEN_EXPIRED",
        AuthError::BadSignature => "BAD_SIGNATURE",
        AuthError::BadIssuer(_) => "BAD_ISSUER",
        AuthError::BadAudience => "BAD_AUDIENCE",
        AuthError::IdpUnreachable(_) => "IDP_UNREACHABLE",
        AuthError::IdpMalformedResponse(_) => "IDP_MALFORMED_RESPONSE",
    }
}
```

```rust
//! PKCE (RFC 7636) artifact generation and brief sessionStorage persistence.
//!
//! The `code_verifier`, `state`, and `nonce` must outlive the IdP redirect.
//! We park them in `sessionStorage` under a single key, which:
//! - is same-origin (the IdP can't read it)
//! - survives the redirect round-trip
//! - is wiped on successful callback validation
//!
//! No tokens ever land in sessionStorage. Only the verifier — which is useless
//! without the corresponding `code` from the IdP.

use base64::Engine;
use gloo_storage::{SessionStorage, Storage};
use serde::{Deserialize, Serialize};
use sha2::{Digest, Sha256};

const STORAGE_KEY: &str = "kronos_pkce";

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PkceArtifacts {
    pub code_verifier: String,
    pub state: String,
    pub nonce: String,
    /// Where the user wanted to go before being redirected to login.
    pub return_to: String,
}

pub fn generate_pkce(return_to: &str) -> PkceArtifacts {
    PkceArtifacts {
        code_verifier: random_base64url(64),
        state: random_base64url(24),
        nonce: random_base64url(24),
        return_to: return_to.to_string(),
    }
}

pub fn code_challenge(verifier: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(verifier.as_bytes());
    base64::engine::general_purpose::URL_SAFE_NO_PAD.encode(hasher.finalize())
}

pub fn persist(artifacts: &PkceArtifacts) {
    let _ = SessionStorage::set(STORAGE_KEY, artifacts);
}

pub fn take() -> Option<PkceArtifacts> {
    let val: Option<PkceArtifacts> = SessionStorage::get(STORAGE_KEY).ok();
    SessionStorage::delete(STORAGE_KEY);
    val
}

fn random_base64url(bytes: usize) -> String {
    let mut buf = vec![0u8; bytes];
    getrandom::getrandom(&mut buf).expect("getrandom failed");
    base64::engine::general_purpose::URL_SAFE_NO_PAD.encode(&buf)
}
```

```rust
use crate::config::Config;
use leptos::prelude::*;
use leptos_router::hooks::use_query_map;
use serde::Deserialize;

#[derive(Deserialize)]
struct TokenResponse {
    access_token: String,
    #[serde(default)]
    id_token: Option<String>,
}

#[component]
pub fn CallbackPage(config: Config) -> impl IntoView {
    let login_state = use_context::<RwSignal<LoginState>>()
        .expect("LoginState context not provided");
    let query = use_query_map();

    let exchange = Action::new(move |_: &()| {
        let config = config.clone();
        let query = query.get();
        async move {
            let code = query.get("code").map(|s| s.to_string());
            let state = query.get("state").map(|s| s.to_string());
            let artifacts = pkce::take();
            let (Some(code), Some(state), Some(artifacts)) = (code, state, artifacts) else {
                return Err::<(), String>("missing code/state or PKCE artifacts".into());
            };
            if state != artifacts.state {
                return Err("state mismatch (possible CSRF)".into());
            }

            let token_endpoint = discover_token_endpoint(
                config.oidc_issuer.as_deref().ok_or("issuer not configured")?,
            )
            .await?;

            let resp: TokenResponse = gloo_net::http::Request::post(&token_endpoint)
                .header("Content-Type", "application/x-www-form-urlencoded")
                .body(form_urlencoded::Serializer::new(String::new())
                    .append_pair("grant_type", "authorization_code")
                    .append_pair("code", &code)
                    .append_pair("redirect_uri", config.oidc_redirect_url.as_deref().unwrap_or(""))
                    .append_pair("client_id", config.oidc_client_id.as_deref().unwrap_or(""))
                    .append_pair("code_verifier", &artifacts.code_verifier)
                    .finish())
                .map_err(|e| e.to_string())?
                .send()
                .await
                .map_err(|e| e.to_string())?
                .json::<TokenResponse>()
                .await
                .map_err(|e| e.to_string())?;

            let claims = decode_unverified_claims(&resp.access_token)?;
            login_state.set(LoginState {
                access_token: Some(resp.access_token),
                id_token: resp.id_token,
                claims: Some(claims),
            });

            // Navigate to the originally requested path.
            let _ = web_sys::window()
                .and_then(|w| w.location().set_href(&artifacts.return_to).ok());
            Ok(())
        }
    });
    exchange.dispatch(());

    view! { <p>"Completing sign in..."</p> }
}

async fn discover_token_endpoint(issuer: &str) -> Result<String, String> {
    let url = format!(
        "{}/.well-known/openid-configuration",
        issuer.trim_end_matches('/')
    );
    let body: serde_json::Value = gloo_net::http::Request::get(&url)
        .send()
        .await
        .map_err(|e| e.to_string())?
        .json()
        .await
        .map_err(|e| e.to_string())?;
    body.get("token_endpoint")
        .and_then(|v| v.as_str())
        .map(String::from)
        .ok_or_else(|| "discovery missing token_endpoint".into())
}

/// Decode JWT claims WITHOUT verifying signature. We trust the token because
/// it came from a direct POST to the IdP's token endpoint over TLS using
/// PKCE — the IdP authenticated to us via TLS cert and the JWT was minted
/// by them. (Defense in depth: a future task adds JWKS-backed verification
/// on the dashboard side.)
fn decode_unverified_claims(jwt: &str) -> Result<Claims, String> {
    let parts: Vec<&str> = jwt.split('.').collect();
    if parts.len() != 3 {
        return Err("malformed JWT".into());
    }
    let payload = base64::engine::general_purpose::URL_SAFE_NO_PAD
        .decode(parts[1])
        .map_err(|e| e.to_string())?;
    let raw: serde_json::Value = serde_json::from_slice(&payload).map_err(|e| e.to_string())?;
    Ok(Claims {
        iss: raw["iss"].as_str().unwrap_or_default().to_string(),
        sub: raw["sub"].as_str().unwrap_or_default().to_string(),
        email: raw["email"].as_str().map(String::from),
        name: raw["name"].as_str().map(String::from),
    })
}
```

```rust
/// Build the IdP authorize URL and navigate to it. Persists the PKCE artifacts
/// in sessionStorage. Designed to be called from a `create_effect` when
/// `LoginState.access_token` is None and `config.auth_disabled` is false.
pub fn redirect_to_idp(config: &Config, return_to: &str) {
    let issuer = config.oidc_issuer.as_deref().unwrap_or("");
    let client_id = config.oidc_client_id.as_deref().unwrap_or("");
    let redirect_url = config.oidc_redirect_url.as_deref().unwrap_or("");

    let artifacts = pkce::generate_pkce(return_to);
    let challenge = pkce::code_challenge(&artifacts.code_verifier);
    pkce::persist(&artifacts);

    let authorize = format!("{}/authorize", issuer.trim_end_matches('/'));
    let url = format!(
        "{authorize}?response_type=code\
         &client_id={cid}\
         &redirect_uri={ru}\
         &scope=openid%20email%20profile\
         &state={state}\
         &nonce={nonce}\
         &code_challenge={ch}\
         &code_challenge_method=S256",
        cid = url_encode(client_id),
        ru = url_encode(redirect_url),
        state = url_encode(&artifacts.state),
        nonce = url_encode(&artifacts.nonce),
        ch = url_encode(&challenge),
    );
    if let Some(w) = web_sys::window() {
        let _ = w.location().set_href(&url);
    }
}

    let id_token = login_state.with(|s| s.id_token.clone());
    login_state.set(LoginState::default());
    if let Some(issuer) = config.oidc_issuer.as_deref() {
        wasm_bindgen_futures::spawn_local({
            let issuer = issuer.to_string();
            async move {
                let url = format!("{}/.well-known/openid-configuration", issuer.trim_end_matches('/'));
                if let Ok(resp) = gloo_net::http::Request::get(&url).send().await {
                    if let Ok(body) = resp.json::<serde_json::Value>().await {
                        if let Some(end_session) =
                            body.get("end_session_endpoint").and_then(|v| v.as_str())
                        {
                            let mut url = end_session.to_string();
                            if let Some(t) = &id_token {
                                url.push_str(&format!("?id_token_hint={}", url_encode(t)));
                            }
                            if let Some(w) = web_sys::window() {
                                let _ = w.location().set_href(&url);
                                return;
                            }
                        }
                    }
                }
                if let Some(w) = web_sys::window() {
                    let _ = w.location().set_href("/");
                }
            }
        });
    }
}

fn url_encode(s: &str) -> String {
    form_urlencoded::byte_serialize(s.as_bytes()).collect()
}
```

```rust
impl Config {
    /// Use HTTP Basic auth with Kronos. The provided client_id and secret are
    /// exchanged by the Kronos API against the configured IdP's
    /// client_credentials grant — Kronos does NOT validate them itself.
    pub fn with_basic(mut self, client_id: impl Into<String>, client_secret: impl Into<String>) -> Self {
        use base64::Engine;
        let raw = format!("{}:{}", client_id.into(), client_secret.into());
        let b64 = base64::engine::general_purpose::STANDARD.encode(raw);
        self.auth_header = Some(format!("Basic {b64}"));
        self
    }

    /// Use HTTP Bearer auth with a JWT obtained externally (e.g. from your
    /// IdP's client_credentials grant or authorization_code flow).
    pub fn with_bearer(mut self, token: impl Into<String>) -> Self {
        self.auth_header = Some(format!("Bearer {}", token.into()));
        self
    }

    /// Deprecated alias of `with_bearer`. Retained for backward compatibility.
    #[deprecated(note = "use with_bearer")]
    pub fn with_token(self, token: impl Into<String>) -> Self {
        self.with_bearer(token)
    }
}
```

````markdown
### Authentication

Kronos uses external OIDC for all production authentication — there is no

- `Bearer <jwt>` — a JWT issued by your configured OIDC provider, validated
````
